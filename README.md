## 这是一个碎碎念

这并非笔者第一次整理此类“资料汇总”或“经验分享”类文稿。回顾此前的初稿与修改版本，由于内容更新不足、结构尚不完善，以及部分信息随着时间推移逐渐失去参考价值，最终效果并未达到预期。

因此，本次版本可视为笔者目前阶段整理完成的终稿。在前两年的文稿基础上，笔者对部分过时信息进行了删减，并结合2026年发布的相关官方文件，对部分内容进行了更新与补充。最终，本资料将托管于 GitHub 平台，供电子JLUer以及对吉林大学电子科学与工程学院相关情况感兴趣的读者查阅与参考。

笔者入学之初，也曾对大学生活抱有许多期待与憧憬。然而，由于未能及时完成从高中到大学学习模式、思维方式以及信息获取方式上的转变，笔者在大学初期经历了较长时间的摸索，也曾在学习规划、发展方向选择等方面遇到诸多困惑。

入学报道期间，班代师姐曾分享过这样一句话：“大学阶段决定发展的关键因素中，能力固然重要，但信息获取与信息利用往往更加关键。”当时笔者对此并没有充分理解。直到亲身经历多次探索与调整后，才逐渐认识到，信息差在大学成长过程中具有非常重要的影响。

一直到当时大三的时候，笔者终于逐渐积累了一定经验，也开始更加明确自身的发展方向。但与此同时，也意识到部分经验如果能够更早获取，或许可以减少许多不必要的试错成本。因此，整理这些资料的初衷之一，便是希望后来者能够在关键阶段获得更多参考，避免因信息不足、规划不足或缺乏准备而错失适合自己的发展机会。

同时，笔者也希望提醒读者，大学生活并非一定会如想象中充满机遇与成长。无论选择平稳度过大学时光，还是希望在某一领域有所突破，都需要建立在对自身情况充分了解和合理规划的基础之上。过高的期待或理想化的想象，往往会带来不必要的落差。

因此，本资料的另一个目的，是结合笔者自身经历以及对部分具有相关经验同学的访谈整理，为读者提供一些具有参考价值的建议。笔者并不希望给出绝对性的答案，而是希望在课程选择、发展规划、考研就业、能力培养等关键节点，为读者提供更多信息来源，帮助大家以更高的性价比进行选择，减少试错成本。

## 结构说明

本文总体分成了：

- `Timeline.md`

  按照时间顺序介绍从新生入学开始到毕业会经历的绝大部分重要事件

- `Daily.md`

  列举了部分生活上可能遇到的问题和推荐的解决方案

- `Learn.md`

  列举了部分学习上可能遇到的问题和推荐的解决方案

- `Pitfalls.md`

  风险管理条目，叙述一些和官方陈述不一致或是官方未公开的事实

- `Concepts.md`

  列举了大部分本科阶段常见的概念以及其解释

  `Resources.md`

  存放了电子专业好用的软件和网站的链接，以及大部分学校官方的链接

- `Easy.md`

  专为家长准备，简要概括全文、重点讲解家长关心的事项。JLUer无需阅读此部分，但是推荐分享给家长阅读。

- `assets`

  存放图片、音频等源文件

- `SubCollect`

  存放投稿，内容形式与`Pitfalls`条目一致，具体见[投稿](#投稿)

> 推荐入学前开始阅读

## 投稿

如果希望对 `SubCollect` 条目进行投稿、补充或更新，请将相关材料发送至：

[NySherSF@proton.me](NySherSF@proton.me)

### 投稿内容

为了便于核实和整理，请尽可能完整地提供以下信息：

- **事件过程**
  - 按时间顺序描述事件经过
  - 尽可能标注具体日期和时间
  - 涉及多人时，请明确区分不同当事人

- **相关证据**
  - 提供能够证明事件经过的相关材料
  - 尽可能标注证据对应的具体时间
  - 说明证据与事件中具体事实之间的对应关系

- **当事人处理方式**
  - 描述当事人采取了哪些措施
  - 标注具体时间
  - 如存在多次沟通，请按照时间顺序整理

- **校方处理方式及回应**
  - 描述相关部门采取了哪些措施
  - 记录校方的正式或非正式回应
  - 标注具体时间
  - 如存在书面通知、聊天记录、电话录音等，可以一并提供

- **学生看法**
  - 可选
  - 可以提供当事人或其他学生对于事件的看法
  - 应与客观事实、证据进行区分

### 材料格式

为方便后续整理，请尽量按照以下方式提交：

- 截图：`.jpeg` / `.jpg` / `.png`
- 聊天记录：请提供完整上下文，避免只截取单条消息
- 图片证据：尽可能保留原始信息，不要进行二次编辑
- 多张图片：建议按照事件发生时间顺序编号

> 请勿使用 PDF 格式提交材料

### 内容要求

投稿内容应尽可能遵循以下原则：

1. **客观描述事实**
2. **区分事实、证据与个人观点**
3. **尽可能提供具体时间、地点和相关人员**
4. **不要刻意删减可能影响事件判断的上下文**
5. **不要对无法确认的内容直接下结论**
6. **不要为了增强事件严重程度而夸大、虚构或加工事实**

> **投稿材料可以包含主观观点，但最终进入 `SubCollect` 的事件描述应当尽可能以可验证的客观事实为基础。事实、推测和观点应当明确区分。**

### 隐私与敏感信息

如果材料中包含与事件无关的个人信息，请在投稿前进行必要的遮挡。

> 对于能够证明事件真实性且与事件直接相关的信息，不建议在不必要的情况下进行修改或删减。

### 投稿目的

不是单纯收集负面事件，而是记录校园生活中值得后来者注意的问题。

因此，**无论事件最终结论对学校、学院、教师、学生还是其他当事人有利或不利，只要事实清晰、证据充分，都可以投稿。**

投稿材料将根据实际情况进行整理、核实和编写；投稿不代表相关内容一定会被收录。
